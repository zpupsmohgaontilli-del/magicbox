# 📦 MagicBox — Interactive STEM Simulations

MagicBox is a lightweight, responsive web platform designed to host interactive mathematics and science learning tools and simulations for classroom teaching and self-paced student exploration.

Built with clean, vanilla web technologies, MagicBox requires zero installation, adapts dynamically across screens (smartphones, tablets, PCs, and Interactive Flat Panels), and runs directly in any modern browser via GitHub Pages.

## ✨ Features

- **Google-Style Landing Interface:** Clean, approachable typography and distinct visual branding.
- **Dynamic Category Filtering:** One-click toggling between **Maths** and **Science** simulations.
- **Fully Responsive & Touch-Friendly:** Fluid layouts optimized for mobile devices and large interactive touch displays.
- **Zero-Dependency Core:** Pure HTML5, CSS3, and modern vanilla JavaScript for high-speed loading even on low-bandwidth school networks.
- **Modular Simulation Engine:** Easily extendable via a central registry.
